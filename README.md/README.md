# Stardew AI 🌱

Stardew Valley hakkında Türkçe sorular sorabileceğin, Python ve Flask kullanılarak geliştirilmiş bir yardımcı web uygulaması.

## Proje Hakkında

Stardew AI; karakterler, mahsuller, balıklar ve madenler gibi oyun verilerini kullanarak kullanıcıların günlük dilde sorduğu sorulara cevap vermeyi amaçlıyor.

Örneğin:

* "Abigail kim?"
* "İlkbaharda ne ekmeliyim?"
* "En karlı ürün hangisi?"
* "En pahalı balık hangisi?"
* "Bu bütçeyle ne ekebilirim?"
* "Altın cevheri nerede bulunur?"

Uygulama, kullanıcının sorusundaki anahtar kelimeleri ve bilgileri analiz ederek uygun veri kümesinden cevap oluşturuyor.

## Kullanılan Teknolojiler

* Python
* Flask
* HTML / CSS
* CSV
* Git & GitHub

## AI Kullanımı

Projeyi geliştirirken yapay zekâ araçlarından kod yazma, hata ayıklama ve yeni özellikler geliştirme süreçlerinde yararlandım.

Ancak üretilen kodu doğrudan kullanmak yerine test ederek, hataları araştırarak ve projenin ihtiyaçlarına göre değiştirerek ilerledim. Bu süreçte yapay zekâyı yalnızca soru sormak için değil, çalışan bir ürün geliştirme sürecinin bir parçası olarak kullanmayı öğrendim.

## Çalıştırma

Projeyi bilgisayarına klonladıktan sonra gerekli kütüphaneleri yükleyebilirsin:

```bash
pip install flask
```

Ardından:

```bash
python app.py
```

Uygulama varsayılan olarak şu adreste çalışır:

```text
http://127.0.0.1:5001
```
